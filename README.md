# Голосовой бюджет

Учёт трат голосом. Скажите фразу вроде «вчера продукты 1240 и такси 380, пришла зарплата 65 000», и приложение само определит суммы, даты и категории.

- Траты по дням и по категориям
- Доходы по видам: зарплата, аванс, премия, отпускные и свои виды
- Счета: карта, наличные, отложенные; переводы голосом («отложила 5000», «сняла 3000»)

Сайт работает через GitHub Pages. Все записи хранятся только в браузере устройства, в репозиторий они не попадают.

Распознавание речи работает в Chrome (Android, компьютер) и Safari (iPhone).
