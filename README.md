# Голосовой бюджет

Приложение для Android: учёт трат голосом. Скажите фразу вроде «вчера продукты 1240 и такси 380, пришла зарплата 65 000», и приложение само определит суммы, даты и категории.

- Траты по дням и по категориям
- Доходы по видам: зарплата, аванс, премия, отпускные и свои виды
- Счета: карта, наличные, отложенные; переводы голосом («отложила 5000», «сняла 3000»)

## Установка

Скачайте на телефоне [budget-buddy.apk](https://github.com/dariaputilinaboop/budgetbuddy/releases/latest/download/budget-buddy.apk) и откройте файл. Android попросит разрешить установку из этого источника.

Все записи хранятся только на телефоне, в репозиторий они не попадают.

## Как устроено

- `src/app.html` — интерфейс и разбор фраз, `src/native.js` — распознавание речи и хранение через Capacitor.
- `npm run build` собирает `www/`.
- GitHub Actions (`.github/workflows/android.yml`) при каждом изменении в `main` собирает APK и выкладывает его в релиз `latest`.
- `signing/debug.keystore` — ключ подписи, чтобы новые версии ставились поверх старой без потери данных.
